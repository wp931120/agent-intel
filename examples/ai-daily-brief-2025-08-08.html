📰 关键事实

架构：首个"统一模型"——融合 o 系列深度推理和 GPT 系列响应速度，自带实时路由引擎。

基准成绩：AIME 2025 94.6%（数学）、SWE-Bench 74.9%（编程）、Aider Polyglot 88%、MMMU 84.2%（多模态）、HealthBench 幻觉率仅 1.6%（o3 为 15.8%）。

API 定价：$1.25/1M input · $10/1M output —— 仅为 Claude Opus 4.1（$15/$75）的 1/12。开发者 Simon Willison 称"定价 aggressively competitive"。

生态：ChatGPT 周活 7 亿。Apple iOS 26 确认集成。Cursor 在发布数分钟内接入。o3 将于 8月26日从 ChatGPT 退役。

🔍 Agent 开发者的三个关键变化

1. 路由架构可以简化了
以前写 agent 框架需要手动选模型（用 GPT-4o 快查 or 用 o3 深度推理），GPT-5 的内置路由替你判断了。如果你在用 LangChain/LlamaIndex，model router 这个组件可以重新评估必要性。

2. 成本结构质变
重度调用的 Agent（Cursor/Devin 类、自动测试 agent、代码审查 agent）推理成本降为 1/12。以前因为"调用太贵"不敢上线的 agent 场景（如持续后台分析 agent）现在变得可行。

3. 幻觉率大幅下降
1.6% vs 15.8% —— 对需要高可靠性的 agent 输出（代码审查、数据整理、合规检查）是实实在在的进步。但 Guardian 实测发现拼写和地理常识仍有问题，说明通用常识和深度推理是两个维度的能力。
