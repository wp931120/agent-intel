# 🦞 分析流程 — 人话版

拿到信息后，按这四步走：

## 第1步：这消息是什么来头

**先判断类型：**
- 宏观类 — 政策、数据、监管
- 行业类 — 财报、并购、产品、融资
- 突发类 — 宕机、泄露、事故
- 舆论类 — 热搜、通报、社论

**两个问题翻到底：**
- 这条消息出来之前大家以为是什么？
- 如果没有它，现在会是什么情况？

> 比如：OpenAI 发了一个新模型。之前大家以为要半年后才出，那现在提前发就是抢市场信号。

## 第2步：看它怎么说的

**谁在说、说给谁听：**
- 官方发的？媒体发的？匿名爆料？
- 面向大众？面向开发者？面向投资人？

**抠字眼：**
- "适时"vs"尽快"、"探索"vs"启动"、"部分"vs"全面"
- 说了什么，**没说什么**更关键

## 第3步：谁爽了、谁疼了

| | 得利的 | 吃亏的 | 装死的 |
|--|--------|--------|--------|
| 明面 | 被表扬的 | 被点名的 | 没被提的竞品 |
| 暗面 | 上下游配套 | 替代方案 | 还在观望着 |

**记住：** 官方说的 ≠ 真实意图。看被点名的人接下来干嘛。

## 第4步：然后呢？

```
这事发生了 → 市场/监管/大众会怎么反应 → 再下一步会怎样
```

**最后落地：** 对我（投资/工作/判断）意味着什么？

- 短期（1-3 个月）
- 中期（半年到一年）
- 需要盯什么信号

# 📇 信息卡片模板

每条分析最终输出为一张 3:4 竖版卡片，格式如下：

```
┌──────────────────────┐
│  🦞 小龙虾深读         │
│  📅 YYYY-MM-DD        │
├──────────────────────┤
│                       │
│  📌 一句话             │
│  （这条信息最核心的判断） │
│                       │
│  🎯 什么来头           │
│  [类别] · [替代了什么] │
│                       │
│  👄 话里有话           │
│  · 谁说/对谁说         │
│  · 关键用词            │
│                       │
│  ⚖️ 谁赢谁输          │
│  👍 受益：xxx          │
│  👎 承压：xxx          │
│                       │
│  🔮 然后呢            │
│  接下来：xxx           │
│  对我：xxx             │
│                       │
│  📎 出处：[短链接]     │
└──────────────────────┘
```
