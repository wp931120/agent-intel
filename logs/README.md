# Agent Intel 日志目录

存放每次情报搜索的记录，用于回溯分析。

## 文件格式

每条记录包含：

```markdown
## YYYY-MM-DD

### Search: <搜索关键词>

- **Tag**: <使用的 tag>
- **Results**: <返回结果数>, <耗时>
- **Language**: <语言>

### Key Finds

- [标题](链接) — 摘要
- [标题](链接) — 摘要

### Notes

观察、总结、待跟进事项
```

## 原则

- **每条搜索一个记录** — 同一批搜索可以合并在同一天
- **关键发现必记** — 有价值的文章、观点、数据
- **来源可回溯** — 带链接
- **定期回顾** — 回顾旧记录发现趋势和遗漏
